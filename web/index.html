配对新设备

执行后输入配对码，再运行 seven-air-link node start --config node.json。Node 以前台进程运行。

重命名设备

撤销设备授权？

现有连接会立即关闭。此凭证将永久失效，重新接入需要新的配对码与配置文件。

在目标设备的终端执行

网页不替远端批准端口。先启动这台设备的 Node，再使用同一配置运行：

seven-air-link share http --name win-api --target 127.0.0.1:8080 --allow-devices SOURCE_DEVICE_ID --allow-owner --config node.json

将 SOURCE_DEVICE_ID 替换为访问侧设备 ID。省略 --allow-owner 后，Owner 只能管理服务，不能直接访问；省略设备授权后，仅共享设备自身能访问。

TCP 服务将 http 换成 tcp。支持数字回环 IP，不接收任意域名或内网地址。

打开独立代理入口

访问权仅绑定这一项服务，有效期 30 分钟。首次访问需要信任同一个 Server 的证书。

代理不转发 Bridge 凭证、浏览器 Cookie 或上游 Set-Cookie。需要完整登录体验时使用本地 TCP 映射。

服务访问权限

Human / Bot 身份

共享设备始终保留自身使用权。保存将关闭当前连接，移除旧浏览器授权；新连接按新权限建立。

添加参与者

默认凭证有效期 30 天。关联设备被撤销时，身份也将不可用。类型不影响消息接口，不授予设备权限。

按提示输入绑定码。只会写入该身份的独立配置；不要共享 Owner 的 admin.json。

文本预览
