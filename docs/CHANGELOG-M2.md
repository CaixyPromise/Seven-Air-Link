# 0.2.0-m2 · 相对 M1 的变更

新增服务注册、回环本机批准、Principal/Device明确区分的服务ACL；新增前台TCP映射和租约；新增独立WSS数据通道、单次票据、双向字节传输与FIN/RESET；新增独立来源HTTP代理与短期单服务浏览器凭证；新增服务/授权/映射Web管理；新增schema2服务持久化及M1原始备份；新增网络故障恢复和可复跑验收。

保持原配对、证书pin、设备撤销、SSE活动、配置接口与旧Python归档。M2以能力字段协商控制扩展；原有仅M1连接不被视作网络就绪。

关键失败边界：ACL/设备撤销关闭已建立流；过期租约即便被续租请求先删除也关闭存量流；目标本机未批准拒绝连接；重连不恢复旧ACL或停用服务；Server重启仅允许新连接恢复，不能“续传”旧TCP。

HTTP代理未与管理UI共用同源路径，且故意不转发业务Cookie/Authorization。需要完整应用语义使用TCP映射。

非本版范围：Bot/member管理、消息/文件迁移、SQLite、UDP、P2P/VPN、HA、系统服务安装和Agent调度。
