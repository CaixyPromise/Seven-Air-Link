# 0.3.0-m3 变更记录

基于实际交付的 M2 源码演进，不是重新搭建的展示工程。

## 新增

Human/Bot Member 独立身份、Owner 批准与一次性领取、凭证轮换/撤销/到期、可选设备生命周期关联。共享频道与私信、同会话回复、关联 ID、发送幂等、游标分页、CLI/SSE 续订与 incoming-only。受 ACL 保护的文件上传下载、哈希校验、附件引用和文本编码预览。嵌入式 Skill。Web 协同空间/参与者、普通身份登录、Owner 身份管理。活动按 actor/correlation 过滤，Member 仅可见自身操作元数据。

## 继承与升级

保留 M2 TLS pin、Node 配对、本机批准、TCP/HTTP 代理与设备授权。服务 ACL 可显式授予 member Principal；绑定设备不继承权限。原 metadata schema 2 备份后升级到 3，原证书、设备凭证与服务配置不变。已用真实发布 M2 二进制验证原地升级。

## 修复与加固

凭证代际绑定阻止轮换后旧票据、Cookie、租约与流复活。永久身份拒绝会终止前台映射而非无限重试。CLI 文本参数值不会被错误识别为全局选项。新配置与下载目标拒绝覆盖，含符号链接/并发创建测试。页面身份切换/退出清空旧消息与草稿，延迟响应按认证 epoch 隔离。

## 明确未交付

SQLite、旧 Python 历史导入、自动垃圾回收/历史清理、全文搜索、已读/执行状态、自定义多频道、AI 自动唤醒、系统服务安装。程序仍是开发验收版本；五平台编译不等于真机通过，离线页面测试不等于真实浏览器联网通过。
